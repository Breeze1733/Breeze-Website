# Breeze

静态文件位于 `dist`，由 Sites 发布；GitHub 的 `sites-frontend/` 保存对应源码。

- `breeze.qzz.io`：静态页面。
- `tools.breeze.qzz.io`：文件中转、云剪贴板、音乐列表及音频文件。
- `api.breeze.qzz.io`：CPA 和 Muse2API 控制面板。
- `openclaw.breeze.qzz.io`：OpenClaw。
- `diptych.breeze.qzz.io`：Diptych 服务。

网站更新由 GitHub 源码经 Sites 保存版本并发布；私有数据、上传文件和凭据不应提交至仓库。
